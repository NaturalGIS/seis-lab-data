# SeisLabData documentation

SeisLabData is a web application for cataloguing IPMA's marine survey data. The catalogue is organised as a
hierarchy of projects, the survey missions carried out within each project and the survey-related records that
describe the datasets produced by each mission. The data files remain in the archive file system, while the
catalogue stores their metadata, their location in the archive and derived previews.

Records can be created by hand or generated by a mission discovery, which scans a mission's directory in the archive
and extracts the spatial extent, temporal extent and other metadata of the files it finds. Published records are
also made available through a [STAC API](user-guide.md#stac-api) and can be exported to GeoNode.
